# File Handling – User Data Storage System

## Description
A Java console application that stores and retrieves user
details using file handling concepts.

## Features
- Stores user data permanently in a text file
- Reads stored records using buffered streams
- Appends data without overwriting existing records
- Creates file dynamically if not present
- Handles IO exceptions safely

## Tools Used
- Java
- IntelliJ IDEA
- Java IO libraries

## How to Run
1. Open the project in IntelliJ IDEA
2. Run UserDataApp.java
3. Enter user details in the console
4. View stored data in the text file
